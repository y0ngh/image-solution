사용 가능한 기능

기능 소개 제공 중인 전체 기능을 확인합니다. 이미지 형식 변환JPG, PNG, WebP 형식을 바꾸고 크기를 조절합니다. 이미지 압축 목표 용량과 품질을 정해 JPG/WebP로 줄입니다. 이미지 회전 및 크롭 기본 편집 후 새 이미지로 저장합니다. 워터마크 추가 텍스트 워터마크를 이미지 위에 넣습니다. 민감정보 가리기 스크린샷의 개인정보 영역을 박스로 가립니다. 배경 제거 선택한 배경색을 투명하게 제거합니다. 스크린샷 합치기 여러 이미지를 가로, 세로, 행과 열 레이아웃으로 합칩니다. PDF 이미지 도구 이미지를 PDF로 묶고 PDF 페이지를 PNG로 변환합니다. 일괄 이미지 처리 여러 이미지를 한 번에 리사이즈하고 변환합니다. JSON CSV 변환 JSON을 CSV로, CSV를 JSON으로 변환합니다. 영수증 도구 영수증 텍스트 CSV와 식사 영수증 PDF를 만듭니다. 사이트 소개 서비스의 목적과 처리 방식을 확인합니다. 문의 오류 제보와 기능 제안을 남깁니다. 개인정보처리방침 파일과 입력값 처리 방식을 확인합니다.

업로드 이미지 크기 변경

원본 비율 유지를 켠 상태에서 너비 또는 높이만 바꾸면 나머지 값이 자동으로 계산됩니다. 출력 형식과 크기를 설정한 뒤 변환 버튼을 누르면 새 이미지 파일이 생성됩니다.

기능 소개

Image Solution은 이미지와 관련한 다양한 솔루션을 제공합니다. 이미지를 크롭, 회전, 압축하거나 형식을 변환, 워터마크를 추가, 사진을 합치는 등 다양한 솔루션을 무료로 제공합니다.

개인정보처리방침 요약

이 사이트의 이미지 변환 기능은 사용자의 브라우저에서 실행됩니다. 현재 구현은 이미지 파일을 외부 서버로 업로드하거나 저장하지 않으며, 변환 결과도 사용자의 기기에서 직접 다운로드됩니다.

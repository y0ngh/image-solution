사용 가능한 기능

기능 소개 제공 중인 전체 기능을 확인합니다. 이미지 형식 변환JPG, PNG, WebP 형식을 바꾸고 크기를 조절합니다. 이미지 압축 목표 용량과 품질을 정해 JPG/WebP로 줄입니다. 이미지 회전 및 크롭 기본 편집 후 새 이미지로 저장합니다. 워터마크 추가 텍스트 워터마크를 이미지 위에 넣습니다. 민감정보 가리기 스크린샷의 개인정보 영역을 박스로 가립니다. 배경 제거 선택한 배경색을 투명하게 제거합니다. 스크린샷 합치기 여러 이미지를 가로, 세로, 행과 열 레이아웃으로 합칩니다. PDF 이미지 도구 이미지를 PDF로 묶고 PDF 페이지를 PNG로 변환합니다. 일괄 이미지 처리 여러 이미지를 한 번에 리사이즈하고 변환합니다. JSON CSV 변환 JSON을 CSV로, CSV를 JSON으로 변환합니다. 영수증 도구 영수증 텍스트 CSV와 식사 영수증 PDF를 만듭니다. 사이트 소개 서비스의 목적과 처리 방식을 확인합니다. 문의 오류 제보와 기능 제안을 남깁니다. 개인정보처리방침 파일과 입력값 처리 방식을 확인합니다.

Privacy Policy

개인정보처리방침

시행일: 2026년 6월 10일

1. 개인정보 수집 여부

현재 Image Solution는 회원가입, 로그인, 문의 양식, 결제 기능을 제공하지 않습니다. 따라서 사용자의 이름, 이메일 주소, 전화번호와 같은 직접 식별 개인정보를 별도로 입력받지 않습니다.

2. 이미지 파일 처리 방식

사용자가 선택한 JPG 이미지는 브라우저에서 읽히고, JavaScript와 캔버스 기능을 통해 PNG로 변환됩니다. 현재 구현은 이미지 파일을 운영자 서버로 업로드하거나 저장하지 않습니다. 변환 결과는 사용자의 브라우저에서 생성되어 사용자의 기기로 다운로드됩니다.

3. 데이터 및 영수증 처리 방식

JSON, CSV, 영수증 텍스트, 식사 내역 입력값, 이미지 편집 파일, 워터마크 대상 이미지, 민감정보 가리기용 스크린샷, 배경 제거용 이미지, 스크린샷 병합용 이미지, PDF 변환 파일은 현재 브라우저에서 처리됩니다. 현재 구현은 변환 대상 데이터, 영수증 입력값, 이미지 파일, 스크린샷 파일, PDF 파일을 운영자 서버로 업로드하거나 저장하지 않습니다.

4. 자동 수집 정보

현재 정적 페이지 자체에는 별도의 방문자 분석 스크립트가 포함되어 있지 않습니다. 다만 Cloudflare Workers 등 호스팅 제공자가 보안, 트래픽 관리, 오류 분석을 위해 IP 주소, 브라우저 정보, 접속 시각, 요청 URL 등의 접속 로그를 처리할 수 있습니다. 해당 처리는 호스팅 제공자의 정책과 설정에 따릅니다.

5. 외부 서비스 이용

사이트 호스팅에는 Cloudflare Workers를 이용합니다. PDF 이미지 도구에서는 PDF 렌더링 모듈을 불러오기 위해 jsDelivr를 이용하며, 문의 링크를 통해 GitHub Issues를 이용하는 경우에는 GitHub의 개인정보처리방침과 이용 조건이 적용됩니다. 사용자가 브라우저에서 선택한 이미지, PDF, JSON, CSV 및 영수증 입력값은 이러한 외부 서비스에 의도적으로 업로드하지 않습니다.

6. Google 광고와 쿠키

Google AdSense 광고가 활성화되면 Google을 포함한 제3자 광고 사업자가 사용자의 이전 사이트 방문 기록을 바탕으로 광고를 제공하기 위해 쿠키를 사용할 수 있습니다. 광고 제공과 성과 측정 과정에서 쿠키, 웹 비콘, IP 주소 또는 기타 식별자가 사용되거나 처리될 수 있으며, 제3자가 사용자의 브라우저에 쿠키를 저장하거나 기존 쿠키를 읽을 수 있습니다.

Google의 광고 쿠키 사용을 통해 Google과 Google의 파트너는 이 사이트 또는 인터넷상의 다른 사이트 방문 기록을 바탕으로 광고를 제공할 수 있습니다. 사용자는 Google 광고 설정에서 맞춤 광고를 사용 중지하거나 광고 개인 최적화 설정을 관리할 수 있습니다. Google이 파트너 사이트의 정보를 사용하는 방식은 Google 파트너 사이트 또는 앱 사용 시 정보 처리 안내에서 확인할 수 있습니다.

7. 동의 관리

유럽경제지역, 영국 또는 스위스 사용자에게 Google 광고를 제공하는 경우에는 관련 법령과 Google의 사용자 동의 정책에 따라 Google 인증 동의 관리 플랫폼을 적용하고 필요한 동의를 받은 후 광고 관련 데이터를 처리합니다. 동의 관리 기능이 준비되지 않은 지역에는 맞춤 광고를 제공하지 않거나 광고 제공을 제한할 수 있습니다.

8. 방침 변경

기능 추가, 광고 서비스 도입, 외부 서비스 변경, 법령 변경 또는 운영 방식 변경이 발생하면 개인정보처리방침을 수정할 수 있습니다. 중요한 변경이 있을 때는 이 페이지의 시행일과 내용을 갱신합니다.

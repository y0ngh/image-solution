사용 가능한 기능

기능 소개 제공 중인 전체 기능을 확인합니다. 이미지 형식 변환JPG, PNG, WebP 형식을 바꾸고 크기를 조절합니다. 이미지 압축 목표 용량과 품질을 정해 JPG/WebP로 줄입니다. 이미지 회전 및 크롭 기본 편집 후 새 이미지로 저장합니다. 워터마크 추가 텍스트 워터마크를 이미지 위에 넣습니다. 민감정보 가리기 스크린샷의 개인정보 영역을 박스로 가립니다. 배경 제거 선택한 배경색을 투명하게 제거합니다. 스크린샷 합치기 여러 이미지를 가로, 세로, 행과 열 레이아웃으로 합칩니다. PDF 이미지 도구 이미지를 PDF로 묶고 PDF 페이지를 PNG로 변환합니다. 일괄 이미지 처리 여러 이미지를 한 번에 리사이즈하고 변환합니다. JSON CSV 변환 JSON을 CSV로, CSV를 JSON으로 변환합니다. 영수증 도구 영수증 텍스트 CSV와 식사 영수증 PDF를 만듭니다. 사이트 소개 서비스의 목적과 처리 방식을 확인합니다. 문의 오류 제보와 기능 제안을 남깁니다. 개인정보처리방침 파일과 입력값 처리 방식을 확인합니다.

개인정보처리방침

시행일: 2026년 6월 9일

1. 개인정보 수집 여부

현재 Image Solution는 회원가입, 로그인, 문의 양식, 결제 기능을 제공하지 않습니다. 따라서 사용자의 이름, 이메일 주소, 전화번호와 같은 직접 식별 개인정보를 별도로 입력받지 않습니다.

2. 이미지 파일 처리 방식

사용자가 선택한 JPG 이미지는 브라우저에서 읽히고, JavaScript와 캔버스 기능을 통해 PNG로 변환됩니다. 현재 구현은 이미지 파일을 운영자 서버로 업로드하거나 저장하지 않습니다. 변환 결과는 사용자의 브라우저에서 생성되어 사용자의 기기로 다운로드됩니다.

3. 데이터 및 영수증 처리 방식

JSON, CSV, 영수증 텍스트, 식사 내역 입력값, 이미지 편집 파일, 워터마크 대상 이미지, 민감정보 가리기용 스크린샷, 배경 제거용 이미지, 스크린샷 병합용 이미지, PDF 변환 파일은 현재 브라우저에서 처리됩니다. 현재 구현은 변환 대상 데이터, 영수증 입력값, 이미지 파일, 스크린샷 파일, PDF 파일을 운영자 서버로 업로드하거나 저장하지 않습니다.

4. 자동 수집 정보

현재 정적 페이지 자체에는 별도의 방문자 분석 스크립트가 포함되어 있지 않습니다. 다만 Cloudflare Pages 등 호스팅 제공자가 보안, 트래픽 관리, 오류 분석을 위해 접속 로그를 처리할 수 있습니다. 해당 처리는 호스팅 제공자의 정책과 설정에 따릅니다.

5. 제3자 제공

현재 사이트 운영자는 사용자가 업로드한 이미지 파일이나 직접 식별 개인정보를 제3자에게 제공하지 않습니다.

6. 방침 변경

기능 추가, 법령 변경, 운영 방식 변경이 발생하면 개인정보처리방침을 수정할 수 있습니다. 중요한 변경이 있을 때는 이 페이지의 시행일과 내용을 갱신합니다.

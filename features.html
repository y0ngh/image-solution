사용 가능한 기능

기능 소개 제공 중인 전체 기능을 확인합니다. 이미지 형식 변환JPG, PNG, WebP 형식을 바꾸고 크기를 조절합니다. 이미지 압축 목표 용량과 품질을 정해 JPG/WebP로 줄입니다. 이미지 회전 및 크롭 기본 편집 후 새 이미지로 저장합니다. 워터마크 추가 텍스트 워터마크를 이미지 위에 넣습니다. 민감정보 가리기 스크린샷의 개인정보 영역을 박스로 가립니다. 배경 제거 선택한 배경색을 투명하게 제거합니다. 스크린샷 합치기 여러 이미지를 가로, 세로, 행과 열 레이아웃으로 합칩니다. PDF 이미지 도구 이미지를 PDF로 묶고 PDF 페이지를 PNG로 변환합니다. 일괄 이미지 처리 여러 이미지를 한 번에 리사이즈하고 변환합니다. JSON CSV 변환 JSON을 CSV로, CSV를 JSON으로 변환합니다. 영수증 도구 영수증 텍스트 CSV와 식사 영수증 PDF를 만듭니다. 개인정보처리방침 파일과 입력값 처리 방식을 확인합니다.

Features

기능 소개

JPG 파일 업로드

사용자는 JPG 또는 JPEG 이미지를 파일 선택 창으로 불러오거나 업로드 영역에 끌어다 놓을 수 있습니다. 파일이 선택되면 원본 크기를 읽어 너비와 높이 입력창에 표시하고, 미리보기 영역에서 이미지를 확인할 수 있습니다.

이미지 크기 변경

업로드한 이미지의 너비와 높이를 픽셀 단위로 조절할 수 있습니다. 원본 비율 유지를 선택하면 하나의 값을 변경할 때 다른 값이 자동으로 계산되어 이미지가 찌그러지는 문제를 줄일 수 있습니다. 원본 크기 복원은 사용자가 변경한 너비와 높이를 업로드 당시 이미지의 원래 픽셀 크기로 되돌리는 기능입니다.

이미지 형식 변환 및 다운로드

JPG, PNG, WebP 이미지를 선택한 출력 형식으로 변환하고, JPG와 WebP는 품질을 설정할 수 있습니다. 변환 버튼을 누르면 브라우저 캔버스에 이미지가 다시 그려지고 저장 가능한 파일이 생성됩니다. 생성된 파일은 사용자의 기기에서 바로 다운로드되며, 서버 저장 공간을 사용하지 않습니다.

이미지 압축

JPG, PNG, WebP 이미지를 브라우저 캔버스에서 다시 인코딩해 파일 크기를 줄입니다. 품질값과 목표 용량을 지정할 수 있으며 결과 이미지를 바로 다운로드할 수 있습니다.

자르기, 회전, 뒤집기

이미지의 원하는 영역을 픽셀 단위로 잘라내고 90도 단위 회전, 가로 뒤집기, 세로 뒤집기를 적용해 새 이미지로 저장할 수 있습니다.

워터마크 추가

이미지 위에 텍스트 워터마크를 넣고 위치, 크기, 색상, 투명도를 조절한 뒤 PNG로 저장할 수 있습니다. 블로그, 상품 이미지, 문서용 이미지에 출처 또는 소유자 표기를 넣을 때 사용할 수 있습니다.

스크린샷 민감정보 가리기

스크린샷을 업로드하고 마우스로 영역을 드래그해 이름, 전화번호, 이메일, 계좌번호 같은 민감정보를 검은 박스로 가릴 수 있습니다. 가린 결과는 PNG로 다운로드됩니다.

배경 제거

이미지에서 제거할 배경색을 클릭해 선택하고 허용 오차를 조절하면 비슷한 색상 영역을 투명하게 처리합니다. 현재 기능은 AI 자동 누끼가 아니라 단색 또는 유사 색상 배경 제거에 적합합니다.

JSON CSV 양방향 변환

JSON 배열 또는 객체를 CSV로 변환하고, CSV 헤더와 행 데이터를 JSON 배열로 다시 변환할 수 있습니다. 파일 업로드 없이 입력창에 붙여넣은 데이터만 브라우저에서 처리합니다.

스크린샷 합치기

여러 장의 스크린샷을 업로드한 뒤 가로 한 줄, 세로 한 줄, 또는 행과 열을 지정한 표 형태 레이아웃으로 하나의 PNG 이미지로 합칠 수 있습니다. 각 이미지는 같은 셀 크기 안에 비율을 유지한 채 배치되며, 셀 간격과 배경색을 조절할 수 있습니다.

영수증 CSV 및 PDF 도구

영수증 텍스트를 붙여넣으면 항목명과 금액을 추정해 CSV로 다운로드할 수 있습니다. 식사한 메뉴와 금액을 직접 입력하면 영수증 형태로 미리보기를 만들고 브라우저의 인쇄 기능으로 PDF 저장이 가능합니다.

PDF 이미지 도구

여러 이미지를 인쇄용 페이지로 묶어 PDF로 저장하거나, PDF.js를 사용해 PDF 페이지를 PNG 이미지로 렌더링할 수 있습니다.

일괄 이미지 처리

여러 이미지를 한 번에 선택해 최대 너비, 최대 높이, 출력 형식, 품질을 적용하고 변환 결과를 순서대로 다운로드할 수 있습니다.
